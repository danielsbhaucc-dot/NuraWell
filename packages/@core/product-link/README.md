# ‏@core/product-link — חיבור מוצר למרכז

החבילה שכל מוצר משתמש בה כדי לבדוק רישיון ולדווח שימוש. אין בה עיצוב, אין תלויות חיצוניות — רק Web Crypto ו־fetch.

## מה יש כאן

| חלק | מה עושה |
|---|---|
| `ProductLink.check()` | בדיקת רישיון מול רשימת המצבים החתומה (`/license-status`). החתימה נבדקת במוצר עצמו. העותק האחרון נשמר לשימוש בלי רשת: עד 6 שעות, ועוד ימי החסד של הרישיון. |
| `ProductLink.count()` / `flush()` | ספירת שימוש לפי יום ושם מדד. נשלח באצוות. לכל אירוע מזהה קבוע, כך ששליחה חוזרת לא נספרת פעמיים. |
| `ProductLink.heartbeat()` | גרסה ומצב (`ok` / `degraded` / `down`). |
| `LightLink` | חיבור קל למוצרים בלי חשבונות שרצים על המכשיר. נשלחים רק מזהה התקנה אקראי, גרסה, מצב ופלטפורמה, וחוזרים דגלי תכונות. שום מידע של המשתמש לא יוצא מהמכשיר. |

## מצב צל (ברירת המחדל, וכרגע המצב היחיד)

`check()` **תמיד מאפשר**. היא מחזירה גם `wouldBlock` ו־`reason`, כלומר מה הייתה מחליטה, ומדווחת את ההחלטה למרכז. המרכז משווה את ההחלטה לאמת שבשרת, ומציג פערים בלוח הבקרה, בעמוד „שימוש ובריאות”. כל שגיאה (רשת, חתימה, קובץ פגום) מסתיימת באישור — נכשל פתוח.

אכיפה דורשת גם `mode: 'enforce'` וגם `enforceApproved: true`. בלי שניהם המצב נשאר צל. האכיפה תופעל רק אחרי אישור מפורש.

## פרטיות

- רק ספירות. אסור לשלוח שמות, מיילים, טלפונים, כתובות IP או מזהי משתמש.
- השרת דוחה (‏422 ‎`pii`) כל מחרוזת שנראית כמו מייל, טלפון, מספר כרטיס, כתובת IP או מספר זהות.
- בהחלטות רישיון נשלח רק מזהה הרישיון (`lic` מהטוקן) — לא מזהה המשתמש. בשרת נשמר ממנו גיבוב בלבד.
- מזהה ההתקנה בחיבור הקל אקראי. הוא לא נגזר מהמכשיר או מהאדם, והתקנה מחדש יוצרת מזהה חדש. בשרת נשמר רק גיבוב שלו.

## אבטחה בצד השרת (`db/functions/product-link`)

- אישור גישה לכל מוצר בנפרד: מזהה מפתח (`x-pl-key`) וסוד HMAC. הסוד נגזר מסוד־על של המרכז, ולא נשמר במסד.
- חתימה: ‏`HMAC-SHA256(secret, ts \n nonce \n path \n sha256(body))`. זמן בטווח ±5 דקות. ‏nonce חד־פעמי — שליחה חוזרת מקבלת 409.
- גוף עד 16KB (בחיבור קל עד 1KB), JSON בלבד (אחרת 415), סכמה קשיחה בלי שדות נוספים (422).
- הגבלת קצב: 120 בדקה לכל מפתח; בחיבור קל 600 בדקה לכל מפתח ו־12 בשעה לכל התקנה (429).
- שמירה מוגבלת: ‏nonce יום, מזהי אירועים 3 ימים, החלטות 30 יום (ועד 5,000 למוצר), התקנות 90 יום, ספירות יומיות 400 יום.

## שימוש — מוצר עם שרת

```ts
import { ProductLink } from '@core/product-link';
const link = new ProductLink({
  productId: 'sample', keyId: env.PL_KEY, secret: env.PL_SECRET, version: '1.1.0',
  endpoint: `${SUPABASE_URL}/functions/v1/product-link`,
  statusUrl: `${SUPABASE_URL}/functions/v1/admin-api/license-status`,
  publicKey, // ‏CryptoKey: המפתח הציבורי של רשימת המצבים, מיובא מ־packages/customers-licensing/keys/status-public.jwk.json
});
const v = await link.check('*', { lic: claims.lic }); // v.allow תמיד true במצב צל
link.count('session.login');
await link.heartbeat('ok');
await link.flush();
```

## שימוש — מוצר על המכשיר בלי חשבונות

```ts
import { LightLink } from '@core/product-link';
const light = new LightLink({ productId: 'my-app', keyId: 'pk_…', endpoint, version: '2.0.0', platform: 'ios', store });
await light.ping();             // מדווח מצב ומושך דגלים
if (light.flag('new-editor')) { /* … */ }
```

`store` הוא מתאם אחסון קטן (`get`/`set`). למשל localStorage, ‏AsyncStorage או קובץ. בלי מתאם הנתונים נשמרים בזיכרון.
