# ערכת אבטחה ופרטיות (security-privacy)
ערכה אחת: כותרות אבטחה, הגבלת קצב, שומר הרשאות, הצפנת שדות (תואמת לפורמט הקיים) , בדיקת סיסמאות שדלפו (`./password`: אורך 12+, לא זהה למייל, לא במאגרי דליפות; נשלחות רק 5 תווים ראשונים של ה-SHA-1)ודיווח מרכזי אופציונלי (כבוי כברירת מחדל).
התקנה: `node scripts/core-sync.mjs <sha> security-privacy` → תלות `"@core/security-privacy": "*"` → `initSecurityPrivacy({ productId })`.
אין לערוך קבצים מותקנים; מתקנים במקור ומסנכרנים מחדש.
