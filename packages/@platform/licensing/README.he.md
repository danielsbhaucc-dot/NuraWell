# רישוי מודולים (@platform/licensing)

## מה זה עושה

מאפשר למכור מודול במנוי חודשי, ולחסום או לשחרר אותו בלחיצה.

**מנוי חודשי (ברירת המחדל):**

1. **חבילה נעולה.** הקוד מגיע נעול. בלי רישיון בתוקף הוא לא נפתח ולא רץ.
2. **תוקף עד החיוב הבא.** הרישיון תקף עד תאריך החיוב הבא ועוד 3 ימי חסד. אחרי תשלום מונפק רישיון חדש.
3. **חסימה ושחרור באמצע החודש.** הרכיב בודק בערך כל 2 דקות קובץ סטטוס חתום, בחינם. חסימה או שחרור נכנסים לתוקף תוך דקות.
4. **בלי חיבור יותר מ-6 שעות, הרכיב נעצר.** אי אפשר "לנתק" אותו ולהמשיך להשתמש.
5. **מי שמשנה את הקוד, הרכיב מפסיק לעבוד.**
6. **ראיות.** בכל עותק יש סימן נסתר של הקונה, ונשמר תיעוד חתום שהקונה אישר את התנאים.

### מה קורה בלוח

| כפתור | מה קורה |
|---|---|
| הנפק רישיון | יוצר רישיון וחבילה נעולה לאתר של הקונה |
| חסום | עוצר את הרכיב (לזמן מוגבל, לתמיד או עד תשלום) עם סיבה |
| שחרר | הרכיב חוזר לעבוד תוך דקות |
| מפתח חדש | מבטל את הרישיון הישן ומנפיק חדש |

### תוספת פרימיום (לא חובה)

"מוח מרחוק": החלק הרגיש של הקוד רץ אצלנו ולא אצל הקונה. מתאים למוצר יקר במיוחד. לא ברירת המחדל, כי כל שימוש נספר כבקשה.

### קוד מלא

קנייה יקרה ונפרדת שבה הקונה מקבל את כל הקוד. משם יש רק הגנה משפטית.

## התקנה

פקודה אחת ושדה אחד בהגדרות, הרישיון שקיבלתם:

```bash
node scripts/modules/install.mjs licensing --target <repo>
```

## הגדרות

השדה היחיד שחובה הוא הרישיון. כל השאר מוגדר מראש בערכים בטוחים.

<details><summary>פרטים טכניים</summary>

- חבילה: AES-GCM. רישיון וקובץ סטטוס: חתימת Ed25519, עם מספר גרסה עולה (גרסה ישנה נדחית).
- `pollMinutes` = 2, `graceHours` = 6 (אחרי זה נעילה), תוקף = החיוב הבא + 3 ימים.
- קובץ הסטטוס מוגש כקובץ סטטי ולא נספר במכסת בקשות.
- פרימיום: `@platform/licensing/gateway`, בקשות חתומות HMAC עם nonce, מפתח לכל התקנה.

</details>

## אבטחה ופרטיות

- מפתח ההנפקה נשמר רק בסביבה, לא בקוד ולא בחבילה.
- ברישיון אין מידע אישי: רק מזהה לקוח, דומיינים ותאריכים.
- סיבת החסימה נשמרת מוצפנת רק אצלנו.
- כל פעולה דורשת הרשאה ואימות נוסף ונרשמת ביומן בלי פרטים אישיים.
- חסימה רק עוצרת את הרכיב. לא מוחקים שום דבר אצל הקונה.

## מגבלות ידועות

- מומחה נחוש עדיין יכול לפרוץ, אבל זה דורש הרבה עבודה, והסימן הנסתר מראה ממי העותק דלף.
- תנאי הרישיון (`LICENSE-TERMS.he.md`) הם טיוטה שעורך דין צריך לעבור עליה.
- מיגרציה `000216` לא מופעלת בלי אישור.
