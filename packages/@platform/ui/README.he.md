# @platform/ui — צבעים ועיצוב משותף

## מה זה עושה
פלטת הצבעים והמשטחים של NuraWell במקום אחד, כך שכל מוצר חדש נראה עקבי. כולל בדיקה שאין רקע לבן טהור.

## למי זה מתאים
- מוצרים חדשים בתוך המשפחה של NuraWell

## דוגמאות שימוש
- מוצר חדש שמקבל את אותם צבעים בשורה אחת
- בדיקה אוטומטית שאין רקע לבן

## יכולות
- פלטת צבעים ראשית
- משטחי זכוכית ללוח הבקרה
- יצירת משתני CSS
- בדיקת "לבן טהור"

## התקנה
1. פקודה אחת: `node scripts/modules/install.mjs ui --target <repo>`
2. הגדרה אחת: מייבאים את הצבעים, או מוסיפים את משתני ה-CSS לדף.

## הגדרות
ראו את הקובץ config.schema.json אם קיים. אם אין, למודול אין הגדרות משלו, והכול מוזרק בקוד על ידי המוצר.

## אבטחה ופרטיות
- אין מידע ואין קוד שרת
- **איפה המידע נשמר:** אין מידע.
- **מפתחות:** קונה או מוצר שמתקין את המודול יוצר את מפתחות ההצפנה שלו אצלו, בזמן ההתקנה. הם לא נשלחים לאף אחד, גם לא אלינו.

## מגבלות ידועות
- פנימי: זהות המותג של NuraWell, לא מיועד למכירה או לשיתוף
- ערכים חייבים להשתנות יחד עם globals.css

## תמיכה
תמיכה דרך בעל הספרייה. תיקונים חוזרים לספרייה כ-PR לריפו NuraWell, עם בדיקות.
