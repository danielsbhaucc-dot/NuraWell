4איך משחזרים, צעד אחרי צעד

שלב א: לפתוח את המפתחות (5 דקות, בלי ידע טכני)
  1. על מחשב (עדיף לנתק את האינטרנט), לפתוח בדפדפן Chrome, Edge או Safari את הקובץ offline-restore.html בלחיצה כפולה.
  2. אם יש לך את הסיסמה: לבחור "יש לי את הסיסמה", ללחוץ על המסגרת ולבחור את keys.sealed.json, להקליד את הסיסמה ולהקיש "שחזור המפתחות".
  3. אם אין סיסמה: לבחור "יש לי 2 חלקי שחזור", לבחור את keys.recovery.json, ולהעתיק או להקליד שני חלקים כלשהם.
  4. לבדוק שטביעות האצבע זהות לטבלה בעמוד הקודם.
  5. ללחוץ "הורדת קובץ המפתחות". יורד קובץ בשם restored.env. זה הקובץ הכי רגיש שיש, ולכן מעבירים אותו רק למי שמחזיר את האתר לאוויר (שלב ב), ובעדיפות על דיסק און קי ולא במייל.
שלב ב: להחזיר את המפתחות לאתר (בשביל מפתח, כ-15 דקות)
  1. להיכנס ל-Vercel, לפרויקט של NuraWell, למסך Settings ואז Environment Variables.
  2. לכל שורה בקובץ restored.env: להוסיף משתנה באותו שם עם אותו ערך, בסביבת Production, מסוג Sensitive.
  3. לבצע Redeploy לגרסה האחרונה.
  4. לבדוק שהאתר נפתח, שמשתמש קיים רואה את הפרטים שלו, ושבמסך הניהול, בלשונית "משפטי", אפשר להפיק תיק ראיות.
  5. למחוק את restored.env מכל מקום שהוא הועתק אליו, ולרוקן את סל המחזור.
דרך חלופית למפתחים: בתיקייה scripts/keys בקוד יש כלי שורת פקודה שעושה בדיוק את אותו שחזור. ההוראות המלאות נמצאות בקובץ docs/security/key-backup.md.

5מתי ליצור גיבוי חדש

  1. כל פעם שמחליפים מפתח (המערכת תזכיר לך).
  2. אם חלק שחזור אבד או נחשף: יוצרים גיבוי חדש, והחלקים הישנים מפסיקים להיות רלוונטיים אחרי שמחליפים את המפתחות.
  3. פעם בשנה: לבדוק שהדפים עדיין קריאים, ולנסות שחזור בדף השחזור (זה לא משנה כלום באתר).
