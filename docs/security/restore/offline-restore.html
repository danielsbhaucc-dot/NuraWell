שחזור מפתחות NuraWell

הדף הזה עובד בלי אינטרנט ובלי להתקין כלום. שום מידע לא נשלח לשום מקום, הכול קורה רק במחשב הזה. אפשר אפילו לנתק את ה-Wi-Fi לפני שמתחילים.

1במה משחזרים?

אפשר להקליד מהדף המודפס. רווחים ושורות חדשות לא משנים. אם יש טעות הקלדה, הדף יגיד.

2המפתחות שוחזרו הצליח

בדקו שטביעות האצבע (12 התווים) זהות לאלה שמודפסות בדף הגיבוי. זה מוכיח שהמפתח הנכון.

שם המפתחטביעת אצבע

את הקובץ הזה מעבירים רק למפתח שמחזיר את האתר לאוויר, ומוחקים אחרי השימוש. ההוראות המלאות במדריך השחזור.
