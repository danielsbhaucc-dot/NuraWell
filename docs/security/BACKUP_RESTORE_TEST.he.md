# בדיקת שחזור גיבוי

**סטטוס: לא בוצעה.** השחזור דורש את המפתח הפרטי של age ואת סוד הגיבוי מ-`/workspace/db-backup`, שלפי ההנחיה אסור לגעת בהם, וגם מעתיק מידע בריאות אמיתי לשרת עבודה. נדרש אישור מפורש.

## תוכנית (לאחר אישור)
1. Postgres 17 זמני ב-Docker מקומי (`--rm`, ללא פורט חיצוני). **לעולם לא לפרוד.**
2. הורדת הגיבוי האחרון דרך URL חתום, אימות hash.
3. `scripts/backup/db-restore.sh` → פענוח age בזיכרון/pipe ושחזור ליעד המקומי בלבד.
4. אימות: ספירת שורות בטבלאות עיקריות מול פרוד (ספירות בלבד, בלי תוכן), בדיקת סכימה ו-RLS קיימים, דגימת פענוח שדה `enc:v1` אחד.
5. מחיקה: `docker rm -f`, מחיקת ה-volume והקובץ המפוענח, `shred` לקבצים זמניים.
6. רישום תוצאה וזמן שחזור (RTO) כאן.
תדירות מומלצת: רבעונית.
